# Skill: Patch Remediation Generator

## Purpose
The **Patch Remediation Generator** authors actionable remediation guidance for confirmed threats.

## Deliverables
1. **Sigma Rules**: Formulate YAML Sigma detection rules based on verified log event IDs, process names, and command lines.
2. **Containment Actions**: Identify target hosts for network isolation, process kills, and credential revocation.
3. **Hardening Recommendations**: Recommend group policy, firewall, or cloud IAM restrictions to prevent recurrence.
