# ACME Retail 3-Minute Morning Huddle Guide

## Core Purpose
The daily morning huddle energizes floor associates, reinforces daily targets, and provides immediate visibility into stock bottlenecks before the doors unlock.

## Huddle Rules
1. **Under 3 Minutes**: Never exceed 3 minutes.
2. **Celebrate Wins First**: Always acknowledge yesterday's top sales associates or star department.
3. **Clear Daily Target**: State the day's revenue goal clearly in dollar terms.
4. **1 Floor Priority**: Pick exactly one actionable operational priority (e.g., fitting room recovery, greeting at entrance, accessory upsell).
