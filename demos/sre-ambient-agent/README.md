# 🛡️ Ambient SRE Log Triage & Threat Hunting Agent

An event-driven **Ambient SRE Agent** built with **Google ADK 2.0 (Agent Development Kit)**, **FastAPI**, **Gemini**, and **BigQuery Model Context Protocol (MCP)**. Generated by **Demo Factory** following Agentic Engineering SDLC best practices.

---

## 🚀 Setup & Execution

### 1. Installation
```bash
make setup
```

### 2. Seeding Mock BigQuery Logs
```bash
python3 -m app.setup_bigquery_mock_data --dry-run
```

### 3. Run the Webhook Server & Dashboard
```bash
make run
```
Access UI at `http://127.0.0.1:8080`

### 4. Run Deterministic Tests & Harness Evals
```bash
make test  # Runs Pytest suite
make eval  # Runs Trajectory & LM Judge Evals
```
